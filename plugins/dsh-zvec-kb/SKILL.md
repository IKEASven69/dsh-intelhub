# dsh-zvec-kb:本地知识库

把用户的文档(md/txt/pdf/docx/代码等)变成可检索知识库。语义+关键词混合检索,结果带来源。

## 何时使用

- 用户提到"我的文档/笔记/手册/资料"并希望 agent 查内容
- 用户给出一个文件夹,说"把这些喂给你/导入知识库"
- 回答需要引用用户私有材料(公司制度、产品手册、调研笔记),而不是公开网络信息

## 工具

| 工具 | 用途 |
|---|---|
| `kb_import` | 导入文件或整个文件夹(绝对路径,支持 `~`)。立即返回队列情况,后台建索引 |
| `kb_search` | 混合检索:自然语言问题或关键词。返回 `文件路径#块号` 来源 + 片段 |
| `kb_list` | 列出已导入文件、块数、索引状态 |
| `kb_delete` | 按路径移除一个文件(只删索引,不动原文件) |

## 要点

- 检索是**语义**的:用户问"怎么配置超时",能找到写"30 秒无响应则中断"的文档——换了说法也能命中
- 结果带 `路径#块号`,引用答案时注明来源;需要更多上下文时直接读原文件(agent 自带文件工具)
- 重复导入同一文件夹是增量的:只处理新增/变更文件
- 首次导入会自动下载本地向量化模型(约 30MB,存 `~/.dsh/dsh-zvec-kb/hf-cache`),全程离线、文档不出本机
- 模型加载期间 `kb_search` 自动退化为关键词检索并在结果里说明,不会失败

## 不做什么

- 不做对话记忆(那是 hindsight/mnemon/ReMe 的领域)——本插件只管用户主动喂进来的文档
- 不修改、不上传任何用户文件
