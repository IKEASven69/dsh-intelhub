# trust-list 审计面板 · 四版审美方向

同一份真实感数据（roster 四维矩阵 / 证据卡 / egress 分级 / 走势 sparkline），四种完全不同的视觉语言。
每版 HTML 可直接双击打开交互预览，PNG 为 1400×920 效果图。

| 版本 | 方向 | 一句话人格 |
|---|---|---|
| v1-印鉴朱砂 | 中式审计文书：墨底 · 朱砂 · 鎏金，判定即「通/警/禁」三枚旋转印章 | 信任是一枚盖下去的印 |
| v2-终端荧光 | 安全运维终端：CRT 荧光绿 + 扫描线 + 琥珀警示，等宽高密度 | 机房里那块常亮的屏 |
| v3-瑞士报告 | 临床体检报告：大留白 · 细线 · 红色只给危险，最理性克制 | 一份不慌张的验单 |
| v4-工程蓝图 | 图纸美学：蓝图网格 · 虚线标注框 · 引线，FIG.01 图注 | 给风险画工程图 |

对比要点：信息架构四版一致（质量徽章常驻 → 矩阵总览 → 证据卡 → egress → 走势），
差异全在气质：印章（文化 identity）/ 终端（极客 identity）/ 报告（专业 identity）/ 蓝图（工程 identity）。
