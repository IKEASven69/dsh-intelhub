# dsh-team-memory · 团队记忆蒸馏插件 · 计划

> 立项:2026-08-21(源自 dsh-hippo 桥方案讨论的自然延伸)
> 状态:**计划,未开工**。项目定位:项目清单 P5,排序在 dsh-hippo 桥 H5 之后(复用其引擎与自我进化循环)。
> 一句话:**把 agent-team 的会话与任务事件,沉淀为整个团队共享的、有分级寿命、可审计退役的记忆。**

---

## 一、依据(为什么是这个位子)

1. **上游有地基、无记忆**:rc.8 把实验性 Agent Teams 收进核心(持久 mailbox `quiet|wakeup` 投递、共享任务 DAG `blockedBy`/`revision` CAS/`writeScopes`、事件溯源回放 `foldTeam()`)——协调正确性已解决,但**成员干完活,经历就散掉了**,没有任何沉淀机制。
2. **记忆类插件全是单人视角**:77 个记忆插件(含两个两万星巨头)均无"团队共享记忆"概念;社区 dsh-agent-teams 插件 499→730⭐(一周),需求被验证。
3. **openhanako 的参照验证**(`_ref/openhanako` 源码已读):其频道系统(bookmark 游标 token 经济、**reply 才写记忆摘要**、MD 文件即人类可读投影、随机点醒主动发言)用 ~1400 行实现完整循环,验证了"说话才入记忆"与"可读投影"两个关键设计;但文件锁仅进程内、无任务依赖、无冲突防护——**生活流最优,工作流不足**。

## 二、架构(三层杂交:agent-team 的正确性 × openhanako 的可读性 × hippo 的记忆模型)

```
① 事件源(只读消费)
   agent-team: TeamMessageSnapshot / TeamTaskSnapshot 事件流
   ——事件溯源/CAS/writeScopes,并发正确性由上游保证
        │ ② 蒸馏(本插件核心)
        ▼
   reply 消息 / 任务完成事件 → distill → 共享记忆库
   记忆带:类型(闲聊|事实|决策|约束|需求)、时间戳、来源事件链(derivedFrom)
   分级寿命:遗忘曲线衰减(τ 按类型) / 长期保留
   退役而非删除:supersededBy + 更改原因,可审计(每条团队信念可溯源)
        │ ③ 投影(两种视图)
        ▼
   频道式 Markdown 导出(人类可读,openhanako 式"文件即真相")
   设置面板:团队记忆列表 / 类型与强度 / 退役审批门 / 团队任务 DAG 可视(flowloom canvas 候选)
```

**团队版自我进化循环**(复用《dsh-hippo桥-方案文档》四·二):
- **总结**:每团队周期把 mailbox+任务事件合成团队级洞察("这类任务我们上次怎么分工的");
- **调研**:外部事实类团队记忆 web 复核,过期→退役提案附证据;
- **预测**:基于团队 patterns 生成"下一步预判卡",新任务开场注入;
- **自退役**:衰减/被矛盾/过期 → 退役候选队列,面板一键审批。

## 三、里程碑

| # | 内容 | 验收 |
|---|---|---|
| **T0** | 骨架 + agent-team 事件读取:拉取一支团队的 mailbox/任务事件流 dump 成 JSON | 能完整导出一个真实团队的全部事件 |
| **T1** | 蒸馏管线:reply 消息与任务完成事件 → distill → 记忆事件(带类型/来源链) | 团队跑一轮任务后,记忆库出现带溯源的可检索条目 |
| **T2** | 面板:团队记忆列表/搜索/类型与强度/退役审批 | 面板能审批一条退役并看到理由链 |
| **T3** | 频道式 MD 投影导出 | 导出的 MD 打开即完整可读的团队协作记录 |
| **T4** | 团队自我进化循环(总结/调研/预测/自退役) | 跑通一个完整周期 |
| **T5** | 发布(MIT → awesome-dsh-plugin 收录 → dsh-market) | 收录通过 |

## 四、风险与对策

| 风险 | 对策 |

## 五、与既有项目的关系

- **dsh-hippo**:共用引擎与自我进化循环——team-memory 是"团队版入口",hippo 是"个人版入口";
- **flowloom**:团队任务 DAG + mailbox 的可视化面板是其 canvas 技术的天然用武之地(候选,不强绑定);
- **depsec**:自退役的"证据链"哲学同源(审计性)。
